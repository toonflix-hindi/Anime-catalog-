# 🎬 AniVerse — Premium Anime Catalogue

A modern, responsive anime catalogue website built with pure HTML, CSS, and JavaScript. Perfect for hosting on GitHub Pages!

## ✨ Features

- 🏠 **Homepage**: Trending, Popular, Recent, Latest Releases
- 🔍 **Search**: Search by title, Japanese title, or alternative title
- 📖 **Details Page**: Complete anime information with watch links
- 🎭 **Genre Filtering**: Browse by 15+ genres
- 📚 **Catalogue**: Sort by A-Z, Latest, Popular, Rating, Year
- 🛠️ **Admin Panel**: Add, edit, delete anime with custom watch links
- 📱 **Responsive**: Works on all devices
- 💾 **Local Storage**: All data saved in your browser

## 🚀 Quick Start

1. Clone this repository
2. Open `index.html` in your browser
3. Start exploring!
